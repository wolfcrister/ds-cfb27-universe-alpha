# CFB 27 Initial Tier Seeding

These rules apply only when creating the inaugural CFB 27 universe.

After the initial alignment is complete, team ratings, rankings, prestige and real-world results no longer determine tier membership. Promotion and relegation are then governed only by results inside this universe.

## Required source data

Use the final official CFB 27 launch data:

- Preseason Top 25
- Overall rating for every included FBS program
- Offensive and defensive ratings where available
- Program locations
- Program prestige only as a late tiebreaker

Do not use previews, beta ratings, unofficial databases or estimated ratings when final launch data is available.

## Tier 1 qualification

Tier 1 contains exactly 32 programs.

1. Include every program in the final preseason Top 25.
2. Remove those 25 programs from the OVR selection pool.
3. Rank all remaining programs by overall rating.
4. Add the seven highest-rated remaining programs.
5. The resulting 32 programs qualify for Tier 1.

The preseason Top 25 has priority. A ranked program remains in Tier 1 even when an unranked program has a higher OVR.

### Ties for the seventh additional place

Resolve a tie at the Tier 1 boundary in this order:

1. Higher defensive OVR
2. Higher offensive OVR
3. Higher program prestige
4. Documented manual decision if still tied

Never use geography to decide Tier 1 qualification. Geography is applied only after the 32 qualifiers are known.

## Tier 3 qualification

Tier 3 contains exactly six Independents.

1. Remove the 32 Tier 1 qualifiers from the full program list.
2. Rank the remaining programs by OVR.
3. Assign the six lowest-rated programs to Tier 3.
4. FedEx University replaces Kennesaw State in the universe and occupies Kennesaw State's applicable place in the source list.

If Kennesaw State would not naturally fall within the bottom six, the final Tier 3 membership must be documented when the full CFB 27 data is available. Do not silently change the six-team structure.

### Ties at the Tier 3 boundary

Resolve a tie in this order:

1. Lower defensive OVR
2. Lower offensive OVR
3. Lower program prestige
4. Documented manual decision if still tied

## Tier 2 qualification

Every program not assigned to Tier 1 or Tier 3 enters Tier 2.

Tier 2 must contain exactly 96 programs under the inherited 134-team model. If CFB 27 contains a different number of eligible teams, stop and document the discrepancy before creating the alignment.

## Geographic conference assignment

Ratings and rankings are ignored after tier qualification.

### Tier 1

- Split the 32 qualifiers between the Big 12 and Big Ten using the inherited strict geographic method.
- Los Angeles is the Big 12 western anchor.
- New York City is the Big Ten eastern anchor.
- Force a final 16/16 split by resolving only natural geographic border cases.
- Sort each conference by latitude.
- Eight northernmost teams form the North division.
- Eight southernmost teams form the South division.

No strength balancing is permitted.

### Tier 2

- Divide the 96 teams into four geographic macro-regions of 24.
- West: Pac-12 and Mountain West.
- Central: Conference USA and AAC.
- South: Sun Belt and SEC.
- East/North: MAC and ACC.
- Split each macro-region into two geographic conferences of 12.

No strength balancing is permitted.

### Tier 3

- Tier 3 programs remain Independents.

## Required audit trail

The inaugural alignment must preserve:

- Full source Top 25
- Full OVR table
- Tier 1 qualification reason for every program
- Tier 3 qualification reason for every program
- All rating ties and tiebreak decisions
- Geographic coordinates or locations used
- All geographic border decisions
- Final conference and division counts

## Locked principle

> Rankings and OVR seed the universe once. Performance governs it forever after.
