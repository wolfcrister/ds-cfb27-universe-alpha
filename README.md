# DS CFB 27 Universe Alpha

Canonical repository for Daniel Sandberg's College Football 27 promotion and relegation universe.

The universe begins with FedEx University, a new corporate university in Memphis, Tennessee, replacing Kennesaw State and entering the football pyramid in Tier 3.

## Core principles

- Performance determines tier placement.
- Geography determines conference placement.
- Confirmed game data takes priority over narrative material.
- Missing statistics are never invented.
- GitHub is the permanent source of truth.
- Markdown stores readable history and narrative.
- YAML stores structured state and data.
- Generated files must never replace canonical source files.

## Operating modes

1. Stats and Records
2. World and League
3. RPG, Media and Career

Prelaunch worldbuilding and technical foundation for the inaugural CFB 27 season.
