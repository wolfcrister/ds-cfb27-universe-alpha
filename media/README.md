# Media Archive

This directory preserves media coverage, interviews, press conferences, features and public narratives from the CFB 27 universe.

## Canon boundaries

Media material is written and treated as coverage from a real alternate college football world.

However, media narratives do not outrank confirmed factual files. When a media piece introduces a new factual detail, that detail becomes canon only when it is directly confirmed by Daniel or recorded in the relevant structured or profile file.

## Archive structure

- `2026/` contains the FedEx University founding year, including the coaching announcement, institutional launch, staff construction, recruiting groundwork and public debate before football begins.
- Future season folders should contain dated media events from that calendar year.

## Event types

Suitable archived events include:

- official press conferences
- one-on-one interviews
- television studio discussions
- newspaper and website features
- radio interviews
- documentary segments
- coaching announcements
- recruiting coverage
- stadium and campus announcements
- employee and community reactions
- controversy and criticism

## Interactive press conferences

During interactive press conferences, the media asks one question at a time unless Daniel requests a complete transcript or packaged media feature.

Completed events should be preserved in full when they materially affect Daniel Sandberg, FedEx University or the wider college football world.
